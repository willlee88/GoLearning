# 課程文案風格（2026-08 改版）

給：**Go 新手**、有一點 Python 經驗、繁體中文讀者。

## 語氣

- 像朋友在旁邊講，多用「你」「我們」
- 少用「吾人／茲／應當／進行某某」
- 專有名詞第一次出現：先白話，再給英文（例：併發＝一次做很多事，英文叫 concurrency）
- 段落短一點，多舉生活或遊戲 Server 小例子

## 結構（每章盡量保留）

1. **這章你會搞懂什麼**（3～5 句人話）
2. **先跟 Python 對一下**（表格可留，文字要白話）
3. **怎麼寫（能跑的最小例子）**
4. **為什麼這樣設計／底層在幹嘛**（新手要的「詳細」放這裡）
5. **遊戲 Server 會用在哪**
6. **請丟掉的舊習慣**
7. **動手練習**
8. **常見坑**

## 深度

- 不要只丟 API 名稱
- 要回答：為什麼、什麼時候用、不用會怎樣、怎麼驗證
- 進階細節可標「進階可先略過」，但主文要夠新手跟完

## 禁止

- 整段機器翻譯腔
- 未解釋的縮寫連發
- 假設讀者已經會 goroutine／interface
