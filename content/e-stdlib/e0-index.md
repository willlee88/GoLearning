## 這章你會搞懂什麼

E 卷不是要你把標準庫背到可以默寫，而是幫你畫一張**工具箱地圖**。

以後寫遊戲 Server 時，你常常會遇到：「計時怎麼做？」「這串 JSON 怎麼穩穩拆？」「設定該從哪裡來？」——答案多半就在標準庫裡。本卷教你**會查、會選、會避開常見坑**；主路徑不一定每章都必讀，需要時當索引翻回來就好。

## 先跟 Python 對一下

| 你在 Python 的感覺 | 在 Go 這邊 |
|--------------------|------------|
| 「標準庫有，但很多事靠第三方」 | 標準庫偏務實，網路／時間／JSON／同步原語很夠用 |
| 文件常看 docs.python.org | 文件看 [pkg.go.dev](https://pkg.go.dev) 或 `go doc` |
| 一個套件常常很大 | 小套件、小介面居多（例如 `io.Reader`） |

心法：不要先問「有沒有框架」，先問「標準庫有沒有夠用的小積木」。

## 地圖（本批）

| 章 | 主題（人話） |
|----|----------------|
| E1 | 時間與計時器：`Sleep`、Ticker、Timer |
| E2 | I/O 抽象：`Reader` / `Writer`，串流怎麼串 |
| E3 | 設定：命令列 flag 與環境變數 |
| E4 | 路徑可攜 + 把靜態檔 embed 進 binary |
| E5 | `encoding/json` 實務與陷阱 |
| E6 | `strings` / `bytes`：搜尋、切割、高效拼接 |
| E7 | `context` 套件速查（跟 C4 呼應） |
| E8 | `sync` 工具箱地圖（跟 C5 呼應） |

## 怎麼用本卷

1. **趕主路徑**：D 卷做完可以直接去 **F0**（網路）；E 當補給站。  
2. **寫 demo 卡住**：例如「房間要 20Hz tick」→ 回 E1；「訊息要 JSON」→ 回 E5。  
3. **想加深**：每章的 L2／常見坑，就是「為什麼這樣用」的地方。

## 遊戲 Server 會用在哪

- **Tick／超時／心跳**：`time`（E1）  
- **讀連線、組幀**：`io`（E2）再接到 F3  
- **監聽位址、靜態目錄**：flag／環境變數（E3）、路徑與 embed（E4）  
- **協定 payload**：JSON（E5）與 G 卷信封  
- **取消連線／關服**：`context`（E7）  
- **Hub、房間表**：`sync`（E8）

## 動手練習

1. 掃過上表，在紙上標「我已經會／半會／完全沒碰」。  
2. 打開 Arena Mini 的 `go.mod`，猜猜它會用到上表哪些章。  

## 常見坑

- **想一次讀完 E 卷再寫程式**：地圖先建立，細節用到再深挖。  
- **標準庫名稱背很多、契約沒搞懂**：例如以為 `Read` 一次就讀完——後面 F3 會狠狠教訓你。
