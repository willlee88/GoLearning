Go Playground

在網頁輸入 package main 程式，送到後端 runner 執行並回傳 stdout / stderr。 僅供學習：有超時、輸出上限，並禁止 net/http、os/exec 等危險能力。

GitHub Pages 純靜態部署沒有 runner：線上執行需本機 Docker（含 runner）才可用。閱讀課程不需要 Playground。

使用說明

  • Docker：網站 :8088 會把 /api/run 轉到 runner 服務。

  • 不適合當公開多租戶裁判系統；僅內網／學習用途。
