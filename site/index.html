把 Go 講清楚
給新手看的、能跟著做

假設你寫過一點 Python。這裡會用比較口語的方式，帶你搞懂 Go 的型別、錯誤處理、併發， 以及這些東西在「遊戲 Server」裡到底怎麼用——不是背單字，是真的能跟得上。

從頭開始（為什麼用遊戲當例子）看建議學習順序依主題翻找

建議先看這幾篇

  1. 1A0 先看這卷要學什麼（語言地基）A 卷在幹嘛：從安裝、package、零值，一路到 slice／map／struct，幫你把 Go 的資料與型別想清楚。
  2. 2A1 先把 Go 裝好，跑出第一個 module安裝官方工具鏈、認識 go.mod，用最小程式確認「能建、能跑」。
  3. 3A2 package：誰能看見誰（大寫才匯出）同一個目錄就是編譯邊界；名稱大寫才能給別的 package 用——比 Python 底線約定硬很多。
  4. 4A3 變數、零值、常數與 iota宣告了就有預設值；用 const／iota 把狀態與列舉寫清楚，少靠字串魔法。
  5. 5A4 控制流：if、for、switch（就這麼精簡）只有一種 for、條件一定是 bool、短宣告有作用域；房間狀態機很適合用 switch 寫。
  6. 6A5 函式與多回傳：（結果, error）文化參數怎麼傳、多回傳怎麼寫；為什麼失敗用回傳值，而不是丟例外。
  7. 7A6 defer：離開函式前一定做的事延遲執行、後進先出；關檔、解鎖、取消 context 的標準寫法。
  8. 8A7 指標：什麼時候要共享同一份資料預設是值拷貝；需要改同一份或表達「可選」才用指標。沒有指標運算，但有 nil。
