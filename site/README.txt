GoLearning - 靜態 HTML 教學站
==============================

建議用法（有 git clone 的電腦）
--------------------------------
在 repo 根目錄雙擊「看課.bat」，或：

  cd site
  start.bat

瀏覽器開 http://127.0.0.1:4321

之後只要：

  git pull
  再開一次 看課.bat（或重新整理瀏覽器）

不必再下載 ZIP。

ZIP / 拷貝資料夾用法
--------------------
1. 解壓或拷貝整個資料夾
2. 雙擊 start.bat
3. 開 http://127.0.0.1:4321

需求
----
- Python 3 或 Node.js（只是開一個很小的本機靜態伺服器）
- 不要直接雙擊 index.html（路徑會壞）
- 若兩者都沒有：把資料夾放到 NAS / IIS / 任何靜態網站空間

不含
----
- 線上跑 Go（Playground，需要 Docker runner）
- Arena Mini 遊戲（需要 Docker）

含
--
完整課程頁：學習路徑、卷冊、搜尋、全部課文。
