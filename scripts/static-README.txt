GoLearning - static HTML teaching site
======================================

No Docker. No GitHub Pages required.

How to open
-----------
1. Unzip / copy this whole folder
2. Double-click start.bat
3. Browser: http://127.0.0.1:4321

Requirements
------------
- Python 3 OR Node.js (only to run a tiny local web server)
- If neither is installed: put this folder on any static host / NAS web root

Not included
------------
- Online Go Playground (needs Docker runner)
- Arena Mini game (needs Docker)

Included
--------
Full course pages: path, volumes, search, all lessons.
